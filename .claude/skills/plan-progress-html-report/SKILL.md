---
name: plan-progress-html-report
description: Use when reporting plan progress or status to the user.
category: reporting
---

When the user asks where a plan stands, deliver an HTML page, not a chat summary.

- Structure: the current stage against the plan's stages; finished items with their real measured numbers; what remains, and which decisions the user must make.
- Take every status and number from the plan document and the commits, not from memory. Mark anything not yet verified.
- Write the page in the user's language. Then reply briefly with the file path or link.
- Check that the page renders before sending it (see html-mockup-visual-check).
