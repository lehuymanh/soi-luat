---
name: vietnamese-decimal-format
description: Use when writing Vietnamese tables with decimal numbers.
category: documentation
---

Write decimals with a comma in Vietnamese documents: `58,6`, `0,710`. Never a dot.

- Apply this to result tables, plan notes and PR text in this repo.
- Convert figures pasted from script output before writing them (`58.6` becomes `58,6`).
- Keep the same rule in percentages and in the text beside tables.
